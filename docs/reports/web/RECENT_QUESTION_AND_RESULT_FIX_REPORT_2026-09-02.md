# 최근 질문·결과 화면 문제 수정 보고서 (2026-09-02)

## 범위

최근 적금 검색 대화에서 관찰된 결과 목록, 예상 금리, 기관명, 판매 상태, 카드 우대 질문, 약관 용어 질문을 점검했다. 문구만 수정하지 않고 표시 계층, 질문 후보 계층, 상품 데이터 계층을 함께 수정했다.

| 비대면 우대 질문이 `조건에 해당` 형식 | 가입 채널을 조건명으로만 저장 | `인터넷뱅킹이나 모바일뱅킹으로 가입할 예정인가요?`로 변경 |
| `교차거래 우대이율` 의미가 불명확함 | 하나의 약관 제목 아래 OR 경로가 소실됨 | `가입 3개월이 지난 달의 급여이체 또는 KB국민카드 30만원 이상` 두 경로를 한 질문에 명시 |
| 의미 불명확 시 사용자가 알아서 확인하도록 안내 | 질문 생성기가 설명 책임을 사용자에게 넘김 | 프롬프트에 대상·행동·기간·판정 기준을 풀어 쓰도록 명시. 구조화 근거가 없으면 질문을 제조하지 않고 데이터 미확인으로 유지 |

## 질문 생성 원칙

1. 약관 제목에 `조건에 해당하는지 알려주세요`를 붙이지 않는다.
2. 사용자가 답할 수 있는 선택 또는 행동을 묻는다.
3. `당행`, `교차거래`, `비대면 우대` 등은 대상·경로·시점을 풀어 쓴다.
4. OR 조건은 가능한 경로를 모두 노출한다.
5. 카드 사용 거절처럼 이미 답한 공통 선호와 충돌하는 질문은 후보 단계에서 제거한다.
6. 같은 사용자 변수를 상품별 질문으로 반복하지 않고 하나의 질문군으로 묶는다.
7. source에 없는 카드 발급, 금액, 기간을 추정하지 않는다.
8. 근거 부족 시 모호한 질문을 만들어 답을 강요하지 않는다.

## 남은 데이터 품질 원칙

`계산 전`은 UI 결함을 숨기는 문구가 아니다. 해당 상품의 기간별 기본금리, 납입 구조 또는 금리 산식이 구조화되지 않았다는 뜻이다. 이 상품들을 실제 예상 금리로 바꾸려면 화면에서 수치를 추정하지 않고 카탈로그의 공식 근거와 계산 필드를 보완해야 한다.
