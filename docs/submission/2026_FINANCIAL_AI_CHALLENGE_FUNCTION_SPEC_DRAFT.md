## 1. MVP 구현 범위*

- 자연어 채팅 기반 금융상품 탐색 및 조건 변경
- 결정론적 사전 질문과 상품별 미확인 조건 질문
- 예금·적금·파킹통장·CMA 통합 검색 및 추천
- 사용자 답변을 반영한 적용 가능 금리·세전 예상 이자 재계산
- 추천 목록, 상품군·1금융권·저축은행·기관 필터, 상품명 검색, 상품 상세, 출처와 Data Gap 표시
- 대화 turn별 LLM 해석·상태 변경·Engine 호출을 확인하는 debug 화면
- normalized 발행 데이터 4,295개 로드 및 판매 중 4,289개 기본 후보 적용
- 우대조건 의미 분석 코드는 포함하되 기본값은 OFF. 운영 데모의 기본 경로는 기존 대화형 탐색·계산이다

## 3. 사용자 이용 흐름*

1. 배포 URL에 접속해 채팅창에 `1년 동안 매달 30만 원씩 넣을 적금을 찾고 있어`처럼 입력한다.
2. AI가 해석한 상품군·기간·금액을 조건 카드에서 확인하고, 이어지는 가입 대상 및 공통 우대 질문에 자연어로 답한다.
3. 서비스가 판매 중 상품을 필터링하고 현재 조건에서 유리한 후보를 계산한다. 질문이 남아 있어도 현재 결과를 먼저 볼 수 있다.
4. 상위 후보의 미확인 조건에 답하거나 `그 조건이 무슨 뜻이야?`라고 질문한다.
5. 답변마다 갱신되는 적용 가능 금리와 세전 예상 이자를 추천 카드에서 확인한다. 필요하면 상품군·1금융권·기관 필터로 목록을 좁힌다.
6. 상품 카드를 눌러 우대조건, 금리 기준일, Data Gap과 출처를 확인한다.
7. 필요하면 대화로 금액·기간·상품군 또는 이전 답변을 변경해 결과를 다시 계산한다.

기본 데모에서는 의미 분석 스위치를 켜지 않는다. 켜면 사전 질문이 끝난 뒤 상위 후보의 못 읽은 우대 원문을 묶음으로 읽고, 목록에 잠정 메모와 계속 분석 버튼이 나타난다. 이 경로는 실험이며 심사 기본 시나리오에 넣지 않는다.

## 4. AI 및 데이터 처리 방식*

```text
사용자 자연어 → LLM의 strict Structured Output → 현재 상태에 차이 반영
→ 공식 상품 조건 평가 → 금리·현금흐름·세전 이자·순위 계산
→ 다음 질문 또는 추천 결과
```

LLM은 자연어 의도·답변 해석, 조건 설명과 결과 문장 생성을 담당한다. 가입 판정, 조건 충족 상태, 적용 금리, 예상 이자와 순위는 결정론적 Engine이 담당한다. 기본 모델은 OpenAI Responses API의 `gpt-5.6-luna`다.

데이터는 2026-09-05 발행 기준 721개 기관의 상품 4,295개, SourceDocument 9,183개와 EvidenceRef 15,430개로 구성되며, 판매 중인 4,289개만 기본 후보로 사용한다. 비교 서비스에서 발견한 원문과 공식 재확인 근거를 구분하고, 확인되지 않은 값은 생성하지 않고 `UNKNOWN`, `UNSUPPORTED` 또는 `Data Gap`으로 유지한다.

MVP는 이름·주민등록번호·계좌번호 입력을 요구하지 않는다. 사용자가 입력한 대화와 금융 선호·의향은 세션 진행 및 debug audit를 위해 서버에 기록될 수 있으므로, 실제 개인식별정보나 계좌정보는 입력하지 않는 것을 원칙으로 한다. 마이데이터 및 실제 금융계좌 조회는 연결하지 않았다.

## 5. MVP 검증 방법*

- 배포 URL: `[배포 URL 입력]`
- 권장 환경: 데스크톱 최신 Chrome
- 별도 계정: `[필요 없음 / 테스트 계정 입력]`

### 검증 시나리오

1. `1년 동안 매달 30만 원씩 넣을 적금을 찾고 있어` 입력
   - 예상: 적금·12개월·월 30만 원이 조건에 반영되고 사전 질문이 이어진다.
2. 사전 질문에 자연어로 답변
   - 예상: 답변이 조건 카드에 반영되고 다음 질문 또는 후보 계산으로 진행한다.
3. 상품별 질문에 `그게 정확히 무슨 뜻이야?` 입력
   - 예상: AI가 조건을 설명하고 답하지 않은 기존 질문을 유지한다.
4. 조건에 `네`, `아니요` 또는 자연어로 답변
   - 예상: 적용 가능 우대와 예상 이자가 재계산되고 다음 상위 후보 조건으로 이동한다.
5. 상품 카드 선택
   - 예상: 상품 주요 조건, 금리 기준일, 출처와 미확인 항목을 확인할 수 있다.
6. `/debug` 접속
   - 예상: 동일 세션의 turn별 대화, LLM 해석, 상태 변경과 Engine 호출을 구분해 볼 수 있다.

의미 분석 ON 경로는 기본 검증 시나리오가 아니다. 2026-09-07 프롬프트 실험은 제한된 원문과 반복 호출의 관찰이며, 브라우저 E2E·카탈로그 전체 정확도·운영 준비 완료를 대체하지 않는다.

### MVP 제한사항

- 실제 상품 가입, 금융기관 계좌·마이데이터 조회는 지원하지 않는다.
- 실시간 이벤트·쿠폰·앱 메뉴 정보는 보유 데이터에 포함된 범위만 안내한다.
- 실적배당 CMA는 확정 수익을 계산하거나 보장하지 않는다.
- 공식 금리·산식이 부족한 상품은 계산 결과 대신 Data Gap을 표시한다.
- AI 응답 속도는 외부 모델 API와 네트워크 상태의 영향을 받을 수 있다.
- 우대 원문 의미 분석은 기본 OFF다. 켜더라도 해석 실패·논리 오류·은행 확인 필요 조건을 금리 확정으로 바꾸지 않는다.
- 발행 카탈로그의 모든 근거가 공식 재확인을 통과했다는 뜻이 아니다.
