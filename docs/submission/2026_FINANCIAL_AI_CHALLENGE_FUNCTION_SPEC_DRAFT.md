화면·제출 양식의 서비스 표기는 **딱금리**다.

## 1. MVP 구현 범위*

- 왼쪽 자연어 대화와 오른쪽 추천 목록이 같은 조건으로 함께 갱신되는 탐색 화면
- 결정론적 사전 질문과 상위 후보의 미확인 조건 질문. 선택형 버튼과 자연어 답변을 함께 받음
- 예금·적금·파킹통장·CMA 통합 검색 및 추천
- 사용자 답변을 반영한 기간·예상 이자·예상 금리·최고 금리 재계산
- 상품군·1금융권·비대면·기관 필터, 상품명 검색, 상품 상세, 출처와 Data Gap 표시
- 대화 turn별 LLM 해석·상태 변경·Engine 호출을 확인하는 debug 화면
- 발행 데이터 4,295개 로드 및 판매 중 4,289개 기본 후보 적용

화면의 `예상 이자`는 Engine이 계산한 세전 예시 금액이다.

## 3. 사용자 이용 흐름*

1. 배포 URL에 접속해 왼쪽 채팅에 `1년 동안 매달 30만 원씩 저축할 상품을 찾고 있어`처럼 입력한다.
2. 위쪽 `AI는 잘 이해했나?`에서 적금·기간·금액을 확인하고, 이어지는 사전 질문에 자연어 또는 선택형 버튼으로 답한다. 오른쪽에는 현재 조건의 추천이 바로 보인다.
3. 마케팅 동의, 자동이체 유지, 특정 은행 주택담보·전세자금 대출, 모바일·인터넷 가입처럼 상위 후보의 미확인 조건에 답하거나 뜻을 다시 묻는다.
4. 답변마다 오른쪽 목록의 기간·예상 이자·예상 금리·최고 금리가 다시 계산된다. 필요하면 `#적금` `#1금융권` `#비대면만` 또는 은행 선택으로 목록을 좁힌다.
5. 상위 3개 카드를 눌러 우대조건과 출처를 확인하고, 대화로 이전 답변을 바꾸면 같은 화면에서 순위가 다시 맞춰진다.

## 4. AI 및 데이터 처리 방식*

```text
사용자 자연어 또는 선택형 답변
→ LLM의 strict Structured Output
→ 현재 상태에 차이만 반영
→ Engine이 가입 조건·금리·현금흐름·세전 이자·순위 계산
→ 왼쪽 다음 질문과 오른쪽 추천을 함께 갱신
```

LLM은 자연어 의도·답변 해석, 조건 설명과 결과 문장 생성을 담당한다. 가입 판정, 조건 충족 상태, 적용 금리, 예상 이자와 순위는 결정론적 Engine이 담당한다. 기본 모델은 OpenAI Responses API의 `gpt-5.6-luna`다.

데이터는 2026-09-05 발행 기준 721개 기관의 상품 4,295개, SourceDocument 9,183개와 EvidenceRef 15,430개로 구성되며, 판매 중인 4,289개만 기본 후보로 사용한다. 비교 서비스에서 발견한 원문과 공식 재확인 근거를 구분하고, 확인되지 않은 값은 생성하지 않고 Data Gap으로 유지한다.

MVP는 이름·주민등록번호·계좌번호 입력을 요구하지 않는다. 대화와 조건 의향은 세션 및 debug audit에 기록될 수 있으므로 실제 개인식별정보나 계좌정보는 입력하지 않는다. 마이데이터 및 실제 금융계좌 조회는 연결하지 않았다.

## 5. MVP 검증 방법*

- 배포 URL: `[배포 URL 입력]`
- 권장 환경: 데스크톱 최신 Chrome
- 별도 계정: 필요 없음

### 검증 시나리오

1. `1년 동안 매달 30만 원씩 저축할 상품을 찾고 있어` 입력
   - 예상: `AI는 잘 이해했나?`에 적금·12개월·월 30만 원이 반영되고, 오른쪽에 적금 추천이 나타난다.
2. 사전 질문과 상위 후보 조건에 `네`, `아니요` 또는 자연어로 답변
   - 예상: 왼쪽 질문이 진행되고 오른쪽 예상 이자·예상 금리·순위가 다시 계산된다.
3. `그 조건이 무슨 뜻이야?` 입력
   - 예상: 조건을 설명하고 아직 답하지 않은 기존 질문을 유지한다.
4. `#1금융권` 또는 `#비대면만`으로 목록을 좁힘
   - 예상: 추천 목록만 걸러지고 대화에서 확인한 조건은 유지된다.
5. 1위 상품 카드 선택
   - 예상: 우대조건, 금리 기준일, 출처와 미확인 항목을 확인할 수 있다.
6. `/debug` 접속
   - 예상: 같은 세션의 turn별 대화, LLM 해석, 상태 변경과 Engine 호출을 구분해 볼 수 있다.

### MVP 제한사항

- 실제 상품 가입, 금융기관 계좌·마이데이터 조회는 지원하지 않는다.
- 실시간 이벤트·쿠폰·앱 메뉴 정보는 보유 데이터에 포함된 범위만 안내한다.
- 실적배당 CMA는 확정 수익을 계산하거나 보장하지 않는다.
- 공식 금리·산식이 부족한 상품은 계산 결과 대신 Data Gap을 표시한다.
- 화면의 예상 이자는 세전 단순 예시이며 실제 지급액과 다를 수 있다.
- AI 응답 속도는 외부 모델 API와 네트워크 상태의 영향을 받을 수 있다.
- 우대 원문 의미 분석은 실험 기능이며 기본값은 꺼져 있다. 심사 기본 경로에 넣지 않는다.
- 발행 카탈로그의 모든 근거가 공식 재확인을 통과했다는 뜻이 아니다.
